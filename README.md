# 🌐 Network Simulation & Packet Analysis

### 📌 Overview

This repository showcases my practical experience in **Computer Networking, Network Simulation, Packet Analysis, and Cybersecurity** using **Cisco Packet Tracer and Wireshark**.

It highlights hands-on networking exercises involving VLAN configuration, IP addressing, static routing, inter-network communication, network troubleshooting, and HTTPS/SSL/TLS traffic analysis.

The repository includes network topology designs, configuration demonstrations, packet simulations, and screenshots documenting practical networking concepts.

## 🔬 Practical Labs

### 1. VLAN Network Design — Cisco Packet Tracer

Designed and configured a simulated network topology using routers, switches, and end devices.

**Key Implementations:**
- Created a network topology using Cisco Packet Tracer.
- Configured VLANs and switch ports.
- Assigned static IP addresses and subnet masks.
- Configured router interfaces and VLAN-related settings.
- Performed connectivity testing through ICMP packet simulations.

**Skills Demonstrated:** VLAN Configuration, Network Segmentation, IP Addressing, Switching, and Network Troubleshooting.

### 2. Inter-Network Communication — Cisco Packet Tracer

Designed a network simulation to establish communication between two separate local area networks (LANs).

**Key Implementations:**
- Developed a multi-router network topology.
- Configured router interfaces and IP addressing.
- Implemented static routing between networks.
- Verified network communication using ICMP packet simulations.
- Analyzed packet transmission across interconnected network devices.

**Skills Demonstrated:** Static Routing, TCP/IP Networking, Router Configuration, Network Connectivity, and Troubleshooting.

### 3. HTTPS/SSL/TLS Traffic Analysis — Wireshark

A network traffic analysis exercise focused on capturing and examining encrypted HTTPS communications using Wireshark.

**Lab Objectives:**
- Capture network traffic while accessing an HTTPS website.
- Identify TCP and TLS packets.
- Examine TLS handshake messages and protocol information.
- Observe encrypted application data.
- Understand how SSL/TLS helps secure communication between clients and web servers.

**Skills Covered:** Packet Analysis, Network Traffic Monitoring, HTTPS, TLS, and Network Security Fundamentals.
